samotest records review evidence

A real evidence workflow: record a browser scenario, copy the GIF artifact, inspect the manifest, then hand the result to the review gate.

$ samotest record readme-demo --format gif
Recorded gif evidence readme-demo
Copied gif recording to docs/demo.gif

$ samotest evidence inspect .samotest/evidence/readme-demo
Evidence run readme-demo
Scenario: readme-demo
Status: passed
Artifacts: 1
  - gif readme-demo-gif artifacts/animation.gif
Observations: 1
  - capture passed after waiting 3500ms

$ samotest gate report --manifest .samotest/evidence/readme-demo/manifest.json

3. GIF + manifest are written
